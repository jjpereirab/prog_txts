// ============================== commands

work on a .root file
	root <filename>

this will get me inside the file, then to explore what's in it
	_file0->ls()

pulling up the TBrowser goes simply as 
	TBrowser anyname

say the tree name is TreeName and a variable inside it is Var. It can be plotted like
	TreeName->Draw("Var")

plotting an operation between variables
	TreeName->Draw("Var1-Var2")

setting an alias to an object, then drawing it
	TreeName->SetAlias("alias","Var1-Var2")
	TreeName->Draw("alias")
	TreeName->Draw("alias","alias>-X_valueInDomain && alias<Y_valueInDomain")
